# 2026-11-25｜换成双向小信号唱片

今天把要提交的项目从价差练习改成「双向小信号唱片 / Mutual Signal Record」。价差路径的代码还在 `starter/src/spread/`，文档还在 `docs/spread-first-path.md`。它留下，但不是这次要交的那条链路。D5 Cron 和官方三件套也不是。

## 项目是哪一条

单人，赛道 2：Set It and Forget It。测试网。运行时没有 AI。

两个人在 Sepolia 上对同一个 `pairId` 发 `SignalSent`。Lasna 比较这两条事件里的时间。一小时内两边都到了，才回调 Sepolia，把相遇压进一个槽。网页再显示图、短诗和一声很短的提示音。链上没有名字和句子。

```
Sepolia SignalBoard
  sendSignal(pairId)
        |
        |  emit SignalSent(sender, pairId, timestamp)
        v
Lasna SignalReactive.react(log)
  remember this person's signal time
  if the other person also signaled within the window: SYSTEM.requestCallbackV_1_0
  else: return (no revert)
        |
        |  Sepolia Callback Proxy
        v
Sepolia EncounterLedger.recordEncounter(...)
  write one slot, emit EncounterUnlocked
        |
        v
Web page shows image / poem / short music
```

更完整的说明在 `docs/signal-first-path.md`。方向卡在 `notes/project-direction.md`。

## 本地

`forge test --match-path test/SignalPath.t.sol --evm-version cancun` 通过，25 个测试。生产编译是 Cancun。Amsterdam 下 `recordEncounter` 第一次大约 138801 gas，低于 Proxy 留给回调的大约 155800。第二次写同一个槽大约 40893 gas。

两个人在测试里用 `vm.prank` 区分。Windows 脚本的第二下要读 gitignored 的 `PRIVATE_KEY_2`。脚本不生成私钥，也不把私钥打出来。没有第二把钥匙时，`waveB` 不广播。
