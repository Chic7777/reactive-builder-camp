# 两个交易池的价差检测与测试网套利实验

这是一份方向计划，后面还可以改。它不是已经做成的套利项目。

D5 定时回调实验已经在测试网跑通。那只说明「订阅 → react() → 回调 → 次数用完后停止」这条基础链路可用。套利逻辑、教学模拟池和机会记录都还没有做。

全部使用测试网。不做实盘，也不做跨链双边套利。

## 1. 事件、条件和目标链动作

两个同币对的教学模拟 AMM 池，在同一条 Reactive 支持的测试链上更新储备或价格之后，Lasna 判断有没有潜在价差，再回调目标链把这次机会记下来。

升级目标是：真正执行时，在目标链上重新报价，扣掉手续费和滑点，并预留 gas 安全边际，然后用一笔目标链交易做两次 swap。条件不满足就跳过，或让这笔执行交易回滚。源链事件、Lasna 的 react()、目标链回调是异步的三段链路，不把这条链路称为原子交易。

同链上的原子试执行是升级目标，不是现在必须完成的部分，这里也不声称已经实现。

## 2. 赛道

拟选赛道 2：个人自动化。

只有升级成真实测试执行，并且同时满足 Base Sepolia 或 Unichain Sepolia、全链路延迟，以及「必须用到秒级」这些条件时，才再评估赛道 1。没有运行时 AI，不选赛道 3。

## 3. 本人和现在的做法

Lavie 是链上策略初学者。现在靠人工比较两个池的报价，比较本身就有成本。这个项目要做的是自动筛选机会，不承诺收益。

## 4. 第 2 周结束前的 MVP

第 2 周结束前做到这些：

- 自己建两个池，并明确写成「教学模拟，非真实市场」。
- 能制造价差，并留下完整链路记录。
- 没有机会时跳过。
- 有次数或预算上限。
- 有完整交易证据。

真实 DEX 测试池的地址和流动性还没有核实，这里不编造。用哪条测试网，实现前再核对官方当前支持的网络。
