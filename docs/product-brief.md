# 恋爱脑清醒日历 / Love-Brain Clarity Calendar

赛道 2：Set It and Forget It。单人（Lavie）。只用测试网。日记正文永远不进链、不上服务器、不进 AI。

## 一句话

一张软软的月历，安静地见证你把「恋爱脑」念头放下，继续好好生活。

## 团（thread）状态机（源规则）

所有关联在一起的日子共享**同一个团状态**，互不牵连其他团。

| 状态 | 含义 |
|---|---|
| 没放下 | 默认。新团、或对放下中/已放下的团又写了新的关联条目之后 |
| 放下中 | 用户在该团任一天点了「愿意放下」/「我愿意放下啦」，整团一起等待 |
| 已放下 | 放下中且窗口内没有新的关联写入，Reactive 回调后整团释放 |

转移：

1. 没放下 → 点愿意放下 → 放下中  
2. 放下中 → 窗口内无新关联写入 → 已放下（demo 约 `CALENDAR_WINDOW=300` 秒；真实生活约 3 天；网页「⏩ 时间快进」只完成放下中的团）  
3. 放下中 → 又写一条关联进本团 → 回到没放下（须再次点愿意放下）  
4. 已放下 → 又写一条关联进本团 → 回到没放下（团重新打开）  
5. 全新无关的团从没放下开始；其他团不变  
6. 「和某天有关」会并入那天所在的**整团**（传递闭包），不只是那一天  

只改同一天正文、不新增关联日，**不会**取消放下中。

链上对应：`touch` / `linkAndTouch`（新关联写入）清除 `pledged`+`released`；`pledgeLetGo` 进入放下中；窗口后 `markReleased` 进入已放下。未承诺的团不会被 cron 释放。

## 三分钟演示脚本（也可当 README 开场）

1. 打开网页（演示模式即可）。右上角可切中文 / English。每次刷新先看开场动画。
2. 写下今天的恋爱脑。文字只留在浏览器 localStorage。
3. 若已有往日记录，先答「这次和之前的事有关吗？」：全新一件事，或关联旧心结（可多选 / 从日历选）。连在一起的日子算一团。
4. 格子上会出现贴纸与虚线；可揭开毒舌神谕大卡（预写语气文案库，不是 AI）。
5. 点「我愿意放下啦」或日历里的「愿意放下」。整团进入**放下中**（链上只记承诺事件，不记日记正文）。
6. 若又为同一团写新的关联条目：整团回到**没放下**（链上 touch 清除承诺）；须再次点愿意放下。
7. 若放下中一直无人再关联写入，窗口结束后 Lasna Reactive 回调 Sepolia，整团变为**已放下**，格子变平静。演示模式可用「⏩ 时间快进」。
8. 无关的新团互不影响。
