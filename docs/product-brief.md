# 恋爱脑清醒日历 / Love-Brain Clarity Calendar

赛道 2：Set It and Forget It。单人（Lavie）。只用测试网。日记正文永远不进链、不上服务器、不进 AI。

## 一句话

一张软软的月历，安静地见证你把「恋爱脑」念头放下，继续好好生活。

## 三分钟演示脚本（也可当 README 开场）

1. 打开网页（演示模式即可）。右上角可切中文 / English。
2. 点某一天，写下今天的恋爱脑，比如：「他今天没理我，他是不是不爱我」。文字只留在浏览器 localStorage。
3. 再点另一天写第二条。写之前必须回答：「这次和之前哪一天有关？」可选前几天，或「全新的一件事」。连在一起的日子算一团（一个 thread）。
4. 格子会越来越粉、有点乱。旁边跳出一句毒舌神谕（中英双语文案库，本地关键词匹配，不是 AI）。
5. 点「我愿意彻底放下，继续好好生活」。链上只记这句承诺（事件含义：我愿意好好生活 / I will live well），不记日记正文。
6. 之后如果又为同一团写新条目，会发一笔极小的无内容 touch，告诉 Reactive：这团还活着，等待窗口重新计时。
7. 若整团在窗口内没有任何 touch（真实生活可设 3 天；演示默认约 30–60 分钟，可用环境变量改），Lasna 上的 Reactive 会回调 Sepolia，把这团标成「彻底放下」。相关格子变平静。
8. 放下的团越多，整页配色越冷静。打开当天主页会显示：「恭喜你，依旧在好好生活」。

## 作业要交的三笔交易（部署后由本人本地广播）

| 种类 | 链 | 含义 |
|---|---|---|
| 源链 tx | Sepolia | pledge 或 touch |
| Lasna react tx | Lasna | Reactive 收到事件 / cron 后判断 |
| 目标链回调 tx | Sepolia | 标记 thread 已彻底放下 |

## 隐私与 AI

- 日记：仅浏览器。永不 on-chain，永不发往服务器或 AI。
- AI：只用于开发辅助。运行时没有 AI，神谕来自预写文案库。
