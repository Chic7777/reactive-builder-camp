# 神谕背景图

每个分类一张图。把 Midjourney 导出的 `png` 或 `jpg` 放到这里，并同步改 `app/config.js` 里的 `backgrounds` 映射（网页在 `file://` 下不 fetch `config.json`，以内联配置为准）。

现在仓库里是轻量 SVG 渐变占位，双击 `index.html` 就能看。

分类：

| key | 含义 |
|---|---|
| ignored | 已读不回 / 冷淡 |
| rumination | 胡思乱想 / 他爱不爱我 |
| urgeToText | 想主动联系 |
| jealousy | 比较 / 嫉妒 |
| reunion | 想复合 |
| selfDoubt | 自我怀疑 |
| fallback | 其它 |
